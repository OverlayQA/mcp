MCP 0.4.1: tools reach their handlers again

Candidate verified locally and against production services. Unpublished.

The published 0.4.0 package fails dispatch for 25 of 29 tools. SDK 1.32.1 mistakes the empty annotations object in the positional registration call for a schema and retains it as the callback. The candidate uses explicit registration fields.

Before and after

  • Downloaded npm 0.4.0: the regression reproduces the 25 broken tools; four client-review handlers remain reachable.
  • Packed 0.4.1: all 29 tools reach their handlers; invalid input is refused and the next call still works.
  • Package suite: 54 passing tests, no failures or skips; TypeScript typecheck passed.
  • Real service journeys: 14 passed across local and production. All run-owned projects and labels were removed.

Dispatch tests deliberately remove the isolated credential after startup, so handlers return AUTH_REQUIRED without network calls or writes. Service journeys separately verify successful persistence with real accounts.
